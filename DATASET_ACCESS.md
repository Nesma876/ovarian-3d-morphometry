# Data access

Obtain `Data.zip` from the [ETH Zurich FollicleFinder collection](https://doi.org/10.3929/ethz-c-000802233). Review the source terms and institutional requirements before access or redistribution. The source archive, medical images, DICOM objects, identifying fields, keys, linkage records and pseudonym-level output tables are outside this repository. Use the local preparation step from the README. The original frozen selection and pseudonym context are private.
